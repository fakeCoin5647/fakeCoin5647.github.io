操作指南

  1. 点击下方「生成并下载」，浏览器会在本机生成 词条名.Civ6Map 文件（不经过任何服务器）。
  2. 把下载的文件复制到文明6的世界构建器存档目录（目录不存在就新建）： %USERPROFILE%\Documents\My Games\Sid Meier's Civilization VI\Saves\WorldBuilder
  3. 启动文明6，主菜单选择 世界构建器（World Builder），打开这张地图，即可在完整 3D 引擎里继续加工。
  4. 想直接试玩：在世界构建器里给文明放置出生点后开一局即可。

导出对照说明

  • 草原 / 平原 / 沙漠 / 雪原 → 同名地形；丘陵与山脉 → 对应的丘陵、山地地形
  • 湖泊与岸边浅水 → 海岸（Coast），深水 → 海洋（Ocean）
  • 森林 → 森林地貌，沼泽 → 沼泽地貌，火山 → 山地 + 火山地貌
  • 河流 → 六边形边界河流（靠近世界构建器的河流工具重描可微调）
  • 奇观：圣山 → 乞力马扎罗，魔泉 → 青春之泉，世界树 → 潘塔纳尔，沉没神殿 → 大堡礁
  • 遗迹、神殿、要塞、港口、营地、石阵、凶地等地标没有文明6对应物，不会导出——请在构建器里用图钉或手工补齐
  • 道路 → 文明6道路（ROUTE_ROAD）；物产 → 对应的文明6资源；手动指定的大陆 → 对应大陆
  • 命名过的河流会带上名字一起导出

地图模板与格式研究参考：je-suis-tm/Sid-Meier-s-Civilization-6-modding（MIT，模板文件随本站分发）；算法另参考 Unciv（MPL-2.0）与 Azgaar FMG（AGPL-3.0），完整对照见项目 docs/map-references.md。

从文明6导入（反向对齐）

  1. 在世界构建器里编辑并保存后，选择导出的 .Civ6Map 文件。
  2. 导入会覆盖当前地形、地貌、河流、道路、物产与大陆；城市和自选领地保留，可用撤销找回。
  3. 文明6的冻土会被转成雪原；没有对应物的元素会被跳过。
